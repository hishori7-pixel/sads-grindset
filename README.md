# ⚡ Sads Grindset — Cyberpunk Minimalist Study Tracker

> Ultra-clean, high-contrast OLED dark mode study tracker designed for serious students and grinders. Optimized for touchscreens (Samsung Galaxy S25) and desktop keyboards.

## 🚀 Core Features

- **Live Focus Engine & Subject Stopwatch:** SVG radial dial with dynamic subject glow accents (Emerald, Cyan, Violet, Rose, Amber, Blue).
- **Today's Live Grind Dashboard:** Real-time 6h target progress ring and session logger directly in the 2-column console.
- **Grindset Analytics & 8-Tier Rank Engine:** 
  - *Lvl 1:* Unranked Slacker
  - *Lvl 2:* Dopamine Detoxer
  - *Lvl 3:* Desk Grinder
  - *Lvl 4:* Deep Work Monk
  - *Lvl 5:* Focus Overlord
  - *Lvl 6:* Exam Executioner
  - *Lvl 7:* Synapse Overclocker
  - *Lvl 8:* Sads 100 — God Mode
- **Rolling 40-Week Survival Heatmap:** 280-day academic consistency matrix with interactive hover & tap inspector.
- **7-Stage Spaced Repetition Engine:** Auto-schedules reviews (+1d, +3d, +7d, +14d, +30d, +60d, +90d) with in-app & device recall notifications.
- **Emergency Buffer Mode:** Instant distraction-free backlog destroyer for overdue reviews & pending tasks.
- **Today's Priority Hit-List:** Full-featured task checklist with inline "Focus Now" play buttons and readable high-contrast styling.
- **Cross-Platform UX:** Mobile bottom dock with safe-area padding for Galaxy S25 + Desktop keyboard shortcuts HUD (`Space`, `R`, `N`, `E`, `?`).
- **LocalStorage Persistence:** Automatic continuous client-side sync.

---

## 🛠️ Tech Stack

- **Framework:** React 18 + Vite
- **Styling:** Tailwind CSS v4 (Pure OLED `#09090b` palette)
- **Icons:** Lucide React
- **Audio:** Web Audio API Cyberpunk Sound Synthesizer

---

## 💻 Getting Started Locally

```bash
# Clone the repository
git clone https://github.com/hishori7-pixel/sads-grindset.git

# Navigate to project folder
cd sads-grindset

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

## ⌨️ Global Keyboard Shortcuts

| Key | Action |
|---|---|
| <kbd>Space</kbd> | Start / Pause Live Timer |
| <kbd>R</kbd> | Reset Timer |
| <kbd>N</kbd> | Focus "Add Priority Task" Input |
| <kbd>E</kbd> | Toggle Emergency Buffer Mode |
| <kbd>?</kbd> | Toggle Shortcuts HUD |
| <kbd>Esc</kbd> | Close Modals & Palettes |
